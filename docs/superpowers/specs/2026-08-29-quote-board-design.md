# 報價看板設計規格（Quote Board v1）

- 日期：2026-08-29
- 狀態：已核准（brainstorming 完成）
- 前置：天氣看板（`weather-v1`，Wi-Fi/NTP/JSON/深睡管線已驗證）、SD 相框（`photo-frame-v1`，現行 master，互動/NVS 紀律已驗證）

## 目的

直立安裝的 792x272 電子紙看板，顯示加權指數與自選股報價。情境 C：
**盤中即時更新（每 5 分鐘）＋收盤定格（含時間戳）**。可隨時按鍵立即更新。

## 硬體與不可變約束（見 `docs/device-research.md`）

- 面板 `GxEPD2_579_GDEY0579T93`，實體 792x272；**本應用以直立安裝（實體轉 90°）**，邏輯版面 272x792。
- 按鍵（active-low）：MENU GPIO2、EXIT GPIO1、rocker up GPIO6、down GPIO4、press GPIO5。
- `PWR` LED GPIO41；UART0 GPIO44/43。顯示器電源／接地控制 GPIO7（hibernate 時拉低）。
- 無電池 ADC、無背光、無原生 USB。電池尚未接入（USB 供電）。

## 資料源

- 端點：`https://mis.twse.com.tw/stock/api/getStockInfo.jsp`
- 單次請求帶全部標的：`ex_ch=tse_2330.tw|tse_2317.tw|tse_0050.tw|tse_006208.tw|tse_t00.tw&json=1`
  - 加權指數代號 `tse_t00.tw`（`n`＝「發行量加權股價指數」）。
- 使用欄位（已實測 2026-08-29）：`c` 代碼、`n` 名稱、`z` 最新價、`y` 昨收、`t` 成交時間、`d` 報價日期。
- 漲跌價＝`z - y`；漲跌%＝`(z-y)/y*100`。
- 注意：API 無正式 SLA；回應含 `userDelay:5000` 節流提示（5 分鐘節奏遠低於限制，無礙）。
- 錯誤處理：HTTP/JSON 解析失敗 → 保留舊值並標示「更新失敗」，5 分鐘後重試。
- **備案**：若公開 API 長期不穩，經使用者同意後切換為「本機 Shioaji 橋接」（方案 A）——本規格不含其實作。

## 版面（已確認：直式 A3）

邏輯座標 272x792（直立），以 U8g2 `setDisplayRotation(U8G2_R1)` 轉 90° 寫入實體 framebuffer。

```
┌────────────────────────────┐
│ 08-28 週五          更新 13:33 │   header（16px CJK/Latin）
├────────────────────────────┤
│ 加權指數（28px CJK 加粗）       │
│ 46,331.45（40px 數字）         │
│ ▲ +356.23  +0.77%（22px）     │
├────────────────────────────┤
│ 台積電（20px）                │
│ 2,420.00                    │
│ ▲ +10.00  +0.41%            │
│（…鴻海、元大台灣50、富邦台50…）     │
└────────────────────────────┘
```

- 5 列：加權指數＋4 檔自選股（2330 台積電、2317 鴻海、0050 元大台灣50、006208 富邦台50）——**v1 程式內固定**，改清單需重刷（watchlist 編輯列為 v2 候選）。
- 每列三段：名稱（加權指數 28px，個股 20px）、現價（40px）、漲跌行（22px：▲/▼＋漲跌價＋%）。
- 漲跌符號 ▲▼ 用 `drawTriangle` 手繪（不依賴字型 glyph）；上漲▲、下跌▼。
- header：交易日（`d` 欄轉 `MM-DD 週X`）＋更新時間（盤中＝`t` 欄成交時間，收盤後＝定格時間）；抓取失敗時顯示「更新失敗」。

## 字型策略（本次新增工具鏈，已獲同意）

U8g2 內建中文字型僅 16px；20px／28px 名稱需自製**子集**字型：

- `tools/gen_fonts.py`（PIL 渲染 Noto Sans CJK Bold → BDF → u8g2 `bdfconv` → `.c`），僅含固定所需 glyph：
  - 中文：加權指數、台積電、鴻海、元大台灣50、富邦台50、週五、更新（及所需之 一二三四五、失敗等狀態字）
  - 尺寸：20px（個股名稱）與 28px（加權指數）各一組。
- 數字／符號（0-9, `,` `.` `+` `-` `%`）用 U8g2 內建 Latin 字型（40px 現價、22px 漲跌）；`▲▼` 手繪。
- header 16px：U8g2 unifont CJK 子集（含 ASCII）或併入 gen_fonts 16px 組——實作時以字型覆蓋範圍擇一，spec 不限定。
- `bdfconv` 由 u8g2 工具取得（隨 dependency 安裝或下載對應版本），gen_fonts.py 需在 host 驗證字型輸出正確。

## 狀態機與睡眠排程

```
開機 → Wi-Fi 連線 → NTP 對時 → 依本地時間(UTC+8)判定市場狀態
  ├─ 交易時段（週一~五 09:00–13:30）
  │     抓取 → 渲染 → 深睡 5 分鐘（timer＋EXT1）
  ├─ 收盤後（週一~五 13:30 後）
  │     先做一次收盤定格（若當日尚未做）→ 睡到次交易日 09:00
  └─ 六日
        睡到下週一 09:00
  └─ 國定假日（回傳報價日期 d ≠ 今日）
        睡到隔日 09:00 再試（不需假日曆）
MENU（GPIO2）按下 → 立即抓取渲染 → 依現階段狀態重新安排睡眠
```

- 睡眠一律「timer＋EXT1（MENU）」雙源；深睡前 `uiHibernate` → GPIO7 拉低 → 控制線 hold；喚醒反向重新初始化（沿用相框已驗證流程與零遮罩 EXT1 清除）。
- 時間基準：NTP 同步之 epoch（RTC 於深睡中維持）；所有「睡到某時點」的時長以 epoch 差值計算，max 上限避免溢出（單段睡眠上限設 24 小時，超過則分段）。
- 失敗路徑：抓取失敗但無舊值 → 錯誤畫面 → 5 分鐘重試（不掛收盤/假日長睡眠，避免首啟失敗後長時間無更新）。
- 等待 BUSY 有 timeout 並讓出執行權；禁止無限阻斷等待。

## NVS（僅變更時寫入）

- `quote:data`（上次成功報價結構：5 列 × 代碼/現價/昨收/時間）＋ `quote:ts`（更新時間）。
- 任何欄位值與現存不同才寫入（沿用相框紀律）；抓取成功但值全相同（如假日或盤前）不寫。
- 結構含欄位版本號；解析失敗或版本不符視為無舊值。

## 驗證矩陣

host 端（不需硬體）：
1. `gen_fonts.py` 產出字型含所需 glyph、尺寸正確（20/28px）。
2. 漲跌計算（正/負/零、整數與小數）單元測試。
3. JSON 解析（正/缺欄/格式異常）單元測試。
4. 旋轉映射（272x792 → 792x272，U8G2_R1 座標點對點）host 驗證。
5. 睡眠時長計算（交易日/收盤/六日/跨日上限）單元測試。
6. `pio run` 編譯 SUCCESS。

硬體（逐項記錄結果與時間戳）：
7. 開機：Wi-Fi 連線＋NTP 對時成功。
8. 直立顯示方向正確（加權指數在上、文字正立）。
9. 中文名稱 20px/28px 渲染正確無缺字。
10. 報價數值與證交所網頁一致（2330/2317/0050/006208/指數）。
11. 漲跌▲▼與正負符號正確。
12. header 日期/時間正確。
13. MENU 按下→立即更新→重新睡眠。
14. 盤中 5 分鐘自動更新（2 個以上週期）。
15. 收盤定格＋時間戳正確。
16. 六日/假日睡眠跳過（可改系統時間模擬）。
17. 抓取失敗保留舊值＋「更新失敗」標示＋重試。
18. 20+ 次連續 sleep/wake 無異常（無 Busy Timeout）。
19. 收盤後按 MENU 仍可立即更新並回歸長睡眠。
